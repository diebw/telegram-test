# T+ market — Telegram-бот підтримки та пошуку запчастин

Бот для клієнтів [tplus.market](https://tplus.market):

- **Пошук товару** текстом, голосовим або за фото. Бот визначає модель пристрою (зокрема за заводським кодом:
  CPH2579, SM-A525F, A2588), знаходить сумісні деталі в каталозі T+ і перевіряє сумісність за карткою товару.
- **Звернення до менеджерів**: статус замовлення, скасування, «де кур'єр». Кожне звернення стає окремою темою
  в групі менеджерів; закриті тікети потрапляють в архівний канал.
- **Розсилки** новин з каналу клієнтам і статистика закритих тікетів по менеджерах.

## Файли

| Файл | Що робить |
|---|---|
| `main.py` | Telegram-бот (aiogram 3): меню, тікети, розсилки |
| `tplus_search.py` | Пошук по каталогу T+ через MCP: розбір запиту, моделі, сумісність, відповідь |
| `part_lookup.py` | Пошук в інтернеті артикулів деталей і кодів пристроїв (кеш у `part_codes.json`) |
| `ai_recognition.py` | Розпізнавання фото (OCR або Claude) і голосових |
| `tplus_login.py` | Одноразовий вхід бота в T+ (OAuth), створює `tplus_tokens.json` |
| `tplus_debug.py` | Перевірка пошуку з консолі без Telegram |

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env          # заповніть BOT_TOKEN, MANAGER_GROUP_ID, ARCHIVE_CHANNEL_ID
python tplus_login.py         # один раз: вхід в акаунт T+ для бота
python main.py
```

Перевірити пошук без Telegram:

```bash
python tplus_debug.py акб Redmi Note 12 Pro 5G
```

## Безпека

`.env`, `tplus_tokens.json`, бази `*.db`, `closed_tickets.json` і `part_codes.json` містять токени
або дані клієнтів і виключені з репозиторію через `.gitignore`. Не додавайте їх вручну.
